Forbear プライバシーポリシー

最終更新日: 2026年10月15日

1. 基本方針

Forbearは、習慣の自己管理、行動記録、通知、介入を補助するアプリです。アカウント登録はありません。習慣内容、誓約、メモ、衝動記録、顔スキャンの一時データ、Safari防衛の追加ドメイン、撮影メディアを運営者のサーバーへ送信しません。購入処理と利用権限の確認にはAppleとRevenueCatを使用します。購入に関する情報の取り扱いは第4節に記載します。

2. 端末内に保存する情報

診断結果、ストリーク、ミッション、チェックイン、衝動記録、設定、署名画像、利用者が保存を確定した写真・動画を端末内に保存します。WidgetとSafari拡張との共有にはAppleのApp Group領域を使用します。顔を含む写真・動画と、保存しない顔スキャンの一時データは、次のとおり別の機能で扱います。

3. 顔データ、カメラと写真・動画

3.1 顔スキャンで扱うデータと目的

オンボーディングの任意の「顔スキャン」では、前面カメラのライブ映像と、Apple Visionの VNDetectFaceLandmarksRequest で検出する顔の輪郭、左右の目、眉、鼻、唇などの2Dランドマーク座標を、このデバイス上で一時処理します。点群をプレビューへ重ね、顔検出の有無と点の数から演出用の仮の整数値を作ります。仮値はオンボーディングの表示にのみ使い、保存される最終診断の数値は質問の回答から計算します。顔の見た目から人格、健康状態、能力を評価する機能ではありません。

この機能は顔写真・動画のファイルを作成せず、顔認証や本人特定用のテンプレート・埋め込みも作成しません。顔スキャンの映像、ランドマーク、仮値を、写真ライブラリ、iCloud、運営者、RevenueCat、分析サービス、その他の第三者へ保存・送信・共有しません。

3.2 顔スキャンの保存場所、保持期間と終了方法

顔スキャンのデータは端末のメモリ内だけで扱い、ファイルやデータベースには保存しません。入力フレームとVisionの検出結果はフレーム処理中だけ使用します。プレビュー用の点群は新しいフレームで置き換え、スキャン完了、スキップ、画面を閉じたとき、アプリがバックグラウンドへ移ったときに消去します。演出用の仮値だけがオンボーディングの表示中はメモリに残ることがありますが、永続保存されません。顔スキャン用の保存データや長期の保持期間はありません。

「スキップして診断へ」でスキャンを終了できます。カメラを許可しなくても質問による診断や他の機能を利用できます。カメラの許可はiOSの「設定」で取り消せます。

3.3 利用者が保存する顔写真・動画と用途

顔スキャンとは別に、「定点の顔」「耐えてる顔」の写真や、運動ミッションの「証拠動画」を撮影できます。これらには利用者の顔が写ることがあります。利用者が保存を確定した写真・動画は、日々の記録、記録の振り返り、比較画像、利用者が生成する共有用画像やタイムラプス動画の素材として使います。運動中は端末上のVisionによる身体の関節位置を回数計測に使用します。顔認証や本人特定は行いません。

撮影原本はアプリ専用の Application Support/Captures 領域に保存し、記録の日時、種別、ファイルの参照などを端末内のデータベースに保存します。原本とカメラの作業ファイルにはiOSのファイル保護とバックアップ除外を設定します。運営者やRevenueCatに画像、動画、顔の座標を送信しません。

利用者が「30日動画を生成」を実行した場合、選択対象となる端末内の顔写真から動画を作り、アプリ専用の Application Support/Forbear/Achievements 領域に1本保存します。この保存動画にもファイル保護とバックアップ除外を設定します。以前のバージョンで作った動画は、アプリで読み出す際にこの設定を適用します。この変更が、すでに作成済みの端末バックアップ内のコピーを削除するわけではありません。

3.4 保存する写真・動画の保持期間と削除

撮影した写真・動画の原本には日数による自動削除期限を設けていません。利用者が撮影記録の詳細画面で「消す」を選び、確認ダイアログでも「消す」を選ぶまで、またはForbearを端末から削除するまで保持します。写真・動画を消しても、日数やスコアの数値記録は残ります。ファイル削除に失敗して残った媒体は、次回撮影を開始するときに再度削除を試みます。

保存済みの30日動画は、次に動画を生成して置き換えるか、Forbearを端末から削除するまで保持します。原本の写真を削除しても、すでに生成した30日動画は連動して削除されません。

撮影・合成・書き出しには一時ファイルを使用します。不要になったカメラの作業ファイルは処理の完了・キャンセル時に削除し、中断などで残ったものは次回撮影開始時に削除を試みます。共有用の書き出しファイルは結果画面を閉じたときに削除します。異常終了などで一時領域に残った書き出しファイルは、OSによる一時領域の清掃やアプリの削除まで残る場合があります。

3.5 写真への保存、共有先とバックアップ

書き出した画像・動画を「写真に保存」する場合だけ、写真ライブラリへの追加権限を求めます。既存の写真を読み取る権限は求めません。追加したコピーはAppleの写真アプリが管理し、利用者がiCloud写真を有効にしている場合はAppleの設定に従って同期されることがあります。

iOSの共有画面から送信した場合は、利用者が選んだ相手や外部サービスに、顔を含む画像・動画が渡ります。Forbearが共有先を自動で選んだり、自動投稿したりすることはありません。共有先での保存期間や利用は、そのサービスの規約・ポリシーに従います。

写真アプリ、共有先、すでに作成済みのバックアップのコピーは、Forbear内の原本を消したりForbearを削除したりしても消えません。写真アプリの「最近削除した項目」、共有先、バックアップの各管理機能で別途削除してください。Forbearにはこれらの外部コピーを削除する権限はありません。

4. 購入とRevenueCat

購入、購読、返金はAppleのStoreKitとApp Storeにより処理されます。RevenueCatは、購入履歴、購読・利用権限の状態、匿名App User IDを受け取り、購入確認、権利の有効化、復元、不正防止、購入に関する分析に使用します。SDKの通信には、端末のベンダー識別子（IDFV）、端末機種、OS・アプリ・SDKのバージョン、言語やストア地域などの技術情報も含まれます。

Forbearは匿名App User IDを氏名、メールアドレス、連絡先へ結び付けません。カード番号などの決済情報を取得しません。顔スキャンのデータ、撮影した写真・動画、習慣内容、衝動記録、HealthKit WorkoutをRevenueCatへ送信しません。RevenueCatによる取り扱いは RevenueCatのプライバシーポリシー もご参照ください。

購入確認中にアプリを終了しても再購入を案内しないため、商品識別子、購入処理の開始・完了状態、購入処理の時刻・サーバー確認時刻、匿名App User IDと取引IDのハッシュ値を、端末内の Application Support/PurchaseRecovery に保存します。この確認記録にはレシート原文や生のApp User ID・取引IDを保存せず、運営者やRevenueCatへ送信しません。iOSのファイル保護を設定し、端末のバックアップ対象から除外します。購入状況の再確認と重複した購入操作の防止にだけ使用し、記録があるだけでProを有効にすることはありません。

この記録は、対応する有効な購入権利、検証できた返金・失効、または決済前のキャンセル等を確認したときに削除します。未解決の間は日数だけで自動削除せず、購入の復元とお問い合わせを案内します。Forbearを端末から削除すると端末内の確認記録も削除されます。

5. 分析と追跡

RevenueCatの管理画面で購入に関する分析を行います。広告目的で他社アプリやWebをまたぐ追跡は行いません。RevenueCat以外の外部分析SDKは使用しません。顔スキャンの完了・スキップの内部イベントに、顔画像、座標、点数、仮値を付加しません。

6. HealthKit

利用者がミッション画面で明示操作したときだけ、当日のWorkoutをHealthKitから読み取り、任意のミッション証拠候補として端末内で確認します。ForbearはHealthKitへ書き込まず、Workoutを運営者のサーバーやRevenueCatへ送信しません。HealthKitの許可は任意で、拒否しても他の機能を利用できます。

7. 通知

通知は利用者の端末上で予約されます。通知の許可は任意で、iOSの設定から変更できます。

8. データの削除

アカウントはありません。アプリ内の写真・動画の削除方法と外部コピーの扱いは第3.4節・第3.5節をご確認ください。端末内のアプリデータ全体を削除する場合は、iOSの「Appを削除」を使用してください。「Appを取り除く」はデータを残します。OSが管理する既存バックアップ内の情報は、バックアップの設定から別途管理してください。

アプリを削除してもAppleやRevenueCatの購入記録は自動では削除されず、購読も解約されません。自動更新購読の解約はApp Storeの購読管理から行ってください。プライバシーに関するお問い合わせは、次の連絡先で受け付けます。
