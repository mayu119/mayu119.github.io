Forbear プライバシーポリシー

最終更新日: 2026年8月22日

1. 基本方針

Forbearは、習慣の自己管理、行動記録、通知、介入を補助するアプリです。アカウントを作成せず、習慣内容、誓約、メモ、衝動記録、Safari防衛の追加ドメイン、撮影メディアを運営者が閲覧するためのサーバーを使用しません。購入処理のためRevenueCatを利用しますが、RevenueCatへ送信するのは購入履歴と匿名App User IDに限ります。

2. 端末内に保存する情報

診断結果、ストリーク、ミッション、チェックイン、衝動記録、設定、署名画像、撮影した写真・動画を端末内に保存します。WidgetとSafari拡張との共有にはAppleのApp Group領域を使用します。

3. カメラと写真・動画

カメラは、利用者が任意で写真・動画の記録を作成するときだけ使用します。撮影メディアは端末内に保存され、運営者のサーバーへ送信されません。iOSの共有機能で送信する場合は、利用者自身が送信先を選択します。

4. 購入とRevenueCat

購入、購読、返金はAppleのStoreKitとApp Storeにより処理されます。購入履歴と匿名App User IDはRevenueCatへ送信され、entitlement判定、不正防止、RevenueCat dashboardの分析（App FunctionalityおよびAnalytics）のために使用されます。匿名App User IDはメールアドレス、氏名、連絡先などへリンクしません。Forbearはカード番号などの決済情報を取得しません。習慣内容、衝動記録、写真・動画、HealthKit WorkoutはRevenueCatへ送信しません。

5. 分析と追跡

RevenueCat dashboardでは購入履歴と匿名App User IDを用いた分析を行います。広告目的のトラッキング、他社アプリやWebをまたぐ追跡は行いません。RevenueCat以外の外部分析SDKは使用しません。

6. HealthKit

利用者がミッション画面で明示操作したときだけ、当日のWorkoutをHealthKitからread-onlyで読み取り、任意のミッション証拠候補として端末内で確認します。ForbearはHealthKitへ書き込まず、Workoutを運営者のサーバーやRevenueCatへ送信しません。HealthKitの許可は任意で、拒否しても他の機能を利用できます。

7. 通知

通知は端末上で予約されます。許可は任意で、iOSの設定からいつでも変更できます。

8. データの削除

アプリを削除すると端末内のForbearデータは削除されます。自動更新購読の解約はApp Storeの購読管理から行ってください。
