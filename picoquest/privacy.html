ピコクエ

プライバシーポリシー

最終更新日: 2026年10月20日

Mayu Hayashi（以下「運営者」）は、iPhone アプリ「ピコクエ」（以下「本アプリ」）での情報の扱いを、次のとおり定めます。

1. 基本方針

本アプリにはアカウント登録がありません。氏名、メールアドレス、電話番号、位置情報、連絡先、広告用の識別子は集めません。写真ライブラリの中身も読みません。広告は出さず、他のアプリやウェブをまたぐ追跡（トラッキング）もしません。

2. 端末と iCloud に保存する情報

iCloud で同期する情報

次の情報は、利用者の端末と、利用者本人の iCloud（Apple の CloudKit の非公開データベース）に保存します。運営者はこれらを見ることができません。

  • ルーティン（名前、種類、工程の名前・アイコン・時間、ゴールの時刻、曜日、アラームの時刻、声の案内の有無）
  • 支度の記録（始めた・終えた時刻、工程ごとにかかった時間と結果）

ルーティンや工程の名前は利用者が自由に入力できる文字です。他人に知られたくない内容は入れないでください。

端末だけに保存する情報

次の情報は、利用者の端末の中だけに保存します。iCloud にも運営者にも送りません。

  • あなたの呼び名と、なかま（相棒）の名前（声の案内やホーム画面で呼ぶために使います）
  • 初回設定で選んだ相棒、「朝に困ること」の答え
  • 設定（声の大きさ、振動、効果音、液晶の色、アイコン）
  • 記録の自動のコピー（端末の別の場所に書く JSON ファイル。iCloud からサインアウトしても、ここから戻せます）。端末のバックアップ（iCloud バックアップ、パソコンへのバックアップ）に含まれることがあります
  • 端末内の利用の記録（画面の表示・購入の操作など。下の PostHog に送る内容の控え）
  • 動作の診断情報（MetricKit。クラッシュや動作の重さ）。設定の「診断情報を書き出す」を使ったときだけ、利用者が選んだ相手に渡せます

声の案内は、端末の中で作って読み上げます。読み上げのために文字を外部に送ることはありません。通知とアラームも端末の中だけで予約し、ロック画面・Dynamic Island の表示（Live Activity）も端末の中で動きます。

3. 外部サービスに送る情報

アプリの改善と購入の管理のため、次の外部サービスを使います。氏名・メールアドレス・呼び名・なかまの名前・ルーティンや工程の中身・支度の記録は送りません。

PostHog（アプリの使われ方の分析）

  • アプリを開いた・閉じたこと、初回起動
  • 初回設定のどこまで進んだか、選んだ選択肢（相棒の種類、ルーティンの種類、「朝に困ること」の選択肢、通知・アラームを許可したか）。呼び名となかまの名前は「付けたかどうか」だけを送り、中身は送りません
  • 支度を始めたこと、出発したこと（回数）
  • 購入画面を開いたか、どのプランを選んだか、購入・復元・キャンセル・失敗
  • シェアの画面を開いたか、共有シートで送ったか（送り先の種類。画像や文は送りません）
  • 端末の種類、OS のバージョン、アプリのバージョン、ランダムな識別子
  • 通信の仕組み上、IP アドレスがサービスに届きます

購入画面の見せ方を切り替えるための設定値も、PostHog から受け取ります。

RevenueCat（購入の管理）

  • 購入・無料体験・更新・解約・復元の状況、ランダムな識別子
  • 上の PostHog と同じランダムな識別子（購入の状況と使われ方を合わせて見るため）

これらの情報は、サービスの改善と購入の確認のためだけに使います。利用者個人を特定するためには使いません。第三者への販売はしません。

4. 購入

ピコクエ Pro の購入・更新・解約・返金は、Apple の App Store で行われます。運営者はカード番号などの支払いの情報を受け取りません。無料体験が終わる前のお知らせは、端末の中で予約する通知です。

5. 写真とシェア

クリアのカードを「写真に保存」するときだけ、写真ライブラリへの「追加のみ」の許可を求めます。既存の写真は読みません。シェアは iOS の共有シートで行い、利用者が選んだアプリや相手に、画像と文が渡ります。運営者が自動で投稿したり、送り先を選んだりすることはありません。共有先での保存や利用は、それぞれのサービスの決まりによります。

6. 情報を消すには

  • 本アプリを削除すると、端末内の情報（呼び名、なかまの名前、設定、自動のコピーを含む）は消えます。
  • iCloud の情報は、iPhone の 設定 → Apple アカウント → iCloud → ストレージを管理 → ピコクエ から消せます。
  • 書き出したファイルや、共有先・写真アプリに渡したものは、それぞれで消してください。
  • PostHog・RevenueCat のランダムな識別子は、アプリを入れ直すと新しくなります。分析のデータの削除を希望するときは、下のお問い合わせへご連絡ください。
